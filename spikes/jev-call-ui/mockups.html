Jev call: three layouts

Revised so the roster diagram and the Jev call are both primary components on every layout. Each is built once, with the same header, data and controls, and each layout only changes how the two sit together. Click a piece anywhere and every instance follows the same player.

The players, slots, splits, analyst labels and rule-baseline labels are the real 2026 Wild Card roster bundle (dated 2026-09-27). The request text is what buildProfileRequest produces today. Jev's answers are made up for the mockup; no live call was made.

The two components

Both take the same selected player and the same three label sources (Jev, rule baseline, analyst). Neither can change a run total: the diagram's sizes come from the engine's display layer, and the call is advisory.

Questions
Keyed asks in one call. Today there are two: profile and evidence_sufficient.
Type
choice returns one option plus a full probability distribution. noul returns one probability that the true criterion holds.
Instructions
The sentence the model answers. It forbids arithmetic and prose, so the answer can never become a run total.
Criteria
For a choice, one definition per shape with its recorded rule. For a noul, what true and false mean. The rubric version is part of the cache key.
LAYOUT A

Side by side

Equal halves. The packed board on the left, the call as a column on the right. Reading goes piece, then the call about that piece. This is the closest to the current decision page.

Good for

  • Both components at full height, side by side, with no scrolling between them.
  • Keeps the D-50 board as the decision's diagram.

Costs

  • Each half is narrower, so the board loses some size.
  • On a phone the call drops below the board.
LAYOUT B

Call over board

Stacked, both full width. The call runs across the top as a horizontal strip: questions, state, the profile criteria with answers, and the noul. The board fills the width below and rings every piece where Jev, the rule and the analyst disagree. The call is editable here.

Good for

  • Biggest board of the three, and the call reads in one line across.
  • Editing the call and seeing disagreements land on the board happen on one screen.

Costs

  • The page is tall; the board sits below the fold on a laptop.
  • The horizontal strip needs a wide screen and stacks into the vertical call on phones.
LAYOUT C

Lanes and call

The diagram opens in lanes mode, one lane per profile criterion, so the rubric is the axis and the call beside it explains each lane. Switch the source and pieces move lanes; switch to Packed and the same component becomes the board.

ROSTER SHAPESDECISIONSWILD CARDBoardShapes by criterion14 position players

Good for

  • The criteria and the answers become one picture.
  • The source toggle shows where Jev and the rules part ways.

Costs

  • Lanes say nothing about empty space until you switch to Packed.
  • Two toggles on the diagram is more to learn.
